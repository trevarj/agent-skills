# AGENTS.md

## Skill admission

- Reuse project guidance, global guidance, and existing skills before proposing a new skill.
- Propose a skill only after repeated correction or one costly or high-risk failure. Never create or install one without Trevor's approval.
- Ground every candidate in observed work, corrections, failures, or repeated requests.
- Author positive and near-miss manual cases before promotion, then compare clean sessions with and without the candidate skill.
- Retain only instructions that change outcomes. Delete redundant skills instead of archiving them.
- Add references, scripts, or assets only after real use earns them.

## Target views

- Keep canonical content under `skills/<name>`.
- Curate `targets/agents` and `targets/claude` as relative symlinks to approved canonical skill directories.
- Expose only skills suitable for each target. Do not copy canonical content into target views.
- Keep target names identical to canonical skill directory names.

## Delegation

- Do not recursively delegate. A delegated worker must not spawn or consult another worker.
